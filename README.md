# Texas Holdem Basic

이전 River Room 화면, 누적 통계, 기록 저장 기능을 제거하고 **기본 홀덤 게임 + 핸드별 승률 예측**만 제공하는 Godot 프로젝트입니다.

## 실행
Godot 4.3 이상에서 이 폴더의 `project.godot`를 열고 **F5**를 누르세요. Godot 4.7.2에서 검증합니다. 외부 라이브러리가 필요하지 않습니다.

## 기본 게임
- 플레이어 1명 대 컴퓨터 1명, 각 50,000칩 시작.
- SB 500 / BB 1,000. 딜러는 핸드마다 바뀝니다.
- 프리플랍 → 플랍 → 턴 → 리버 → 쇼다운.
- 체크/콜, 레이즈, 올인, 폴드. 레이즈 입력값은 이번 단계의 **총 베팅액**입니다.
- 양쪽 베팅이 완료되면 `다음 카드 공개`를 누릅니다. 올인에 대한 콜 결정 후에는 자동으로 남은 카드를 공개합니다.
- 상대 패는 쇼다운 때 공개합니다. 폴드로 끝난 경우에는 공개하지 않습니다.
- 최선의 5장으로 10종 족보를 판별하고 킥커와 무승부를 처리합니다.
- 최소 레이즈, 짧은 올인의 레이즈 재개 제한, 미매칭 칩 반환을 처리합니다.
- 종료 후 `다음 핸드`를 누릅니다. 칩이 소진되면 `새 매치`로 양쪽을 50,000칩으로 재설정합니다.
- AI는 자신의 패와 공개 카드로 추정한 승률, 팟 오즈를 이용해 간단하게 행동합니다.

## 승률 예측
게임 오른쪽 패널은 내 두 장과 현재 공개 카드만 사용합니다. 실제 상대 패, 남은 실제 덱, 번 카드는 참조하지 않습니다. 가능한 상대 패가 동일한 확률로 나온다고 가정하므로 상대의 베팅 성향은 반영하지 않습니다.

- 프리플랍·플랍·턴: 임의의 상대 패와 나머지 보드를 3,000회 시뮬레이션합니다.
- 리버: 남은 45장 중 상대 두 장의 조합 **990가지**를 전수 비교합니다. 이 가정 아래 정확한 확률이며, 실제 상대와의 승패가 미리 확정된 값은 아닙니다.
- 승리/무승부/패배 확률을 따로 표시하며, 예상 승률은 **단독 승리 확률**입니다.
- 각 단계의 승률을 화면에 남겨 변화도 비교할 수 있습니다.

상단 **핸드별 승률 계산기**에서 원하는 두 장을 직접 고르면, 공개 카드가 없는 시작 상태의 예상 승률을 5,000회 시뮬레이션합니다. AA, AKs, AKo 등 모든 시작 핸드를 선택할 수 있습니다. `s`는 같은 무늬, `o`는 다른 무늬입니다. 같은 카드 두 장은 선택할 수 없습니다. 표본 추정에는 오차가 있으며 재계산하면 값이 조금 달라집니다.

## 코드
- `main.gd`, `main.tscn`: 기본 화면, 핸드 계산기, AI 진행
- `game.gd`: 분배·베팅·턴·팟 정산
- `poker.gd`: 족보 판정·승률 계산
- `tests.gd`: 족보, 베팅, 300핸드 랜덤 진행, 예측 검증
- `ui_test.gd`: GUI 진행 및 핸드 계산기 통합 검증

테스트: `Godot --headless --path . --script res://tests.gd`

UI 테스트: `Godot --path . --script res://ui_test.gd` (미리보기 PNG를 생성합니다.)

누적 전적이나 플레이 기록을 저장하지 않습니다. 종료 후 다시 실행하면 새 게임을 시작합니다.
