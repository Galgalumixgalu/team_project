# 텍사스 홀덤 — AI 싱글 플레이 / 방 코드 온라인 대전 (Godot 4.7)

이 프로젝트는 **AI와 오프라인으로 플레이하거나**, Supabase Realtime을 이용해 **친구와 방 코드로 1대1 온라인 대전**을 할 수 있는 Godot 프로젝트입니다. IP 주소나 포트를 입력하는 기능은 없습니다.

> 온라인 모드는 공개 Realtime 채널을 이용하는 학습·테스트용 구현입니다. 메시지를 암호화하거나 서버에서 게임 규칙을 검증하지 않습니다. 실제 돈을 걸거나 민감한 정보를 다루는 용도로 사용하지 마세요. 공개 키만 게임에 입력하고 `service_role` 비밀 키는 절대 넣지 마세요.

## Godot에서 실행

1. ZIP을 압축 해제합니다.
2. Godot 4.7에서 폴더 안의 `project.godot`를 가져옵니다.
3. F5를 눌러 실행합니다.
4. 시작 메뉴에서 AI 오프라인 또는 친구와 온라인 플레이를 고릅니다.

## Supabase 한 번 설정하기

1. Supabase에서 프로젝트를 생성하거나 기존 프로젝트를 준비합니다.
2. 프로젝트 설정의 API 항목에서 **Project URL**과 **Publishable key**(또는 기존 프로젝트의 anon public key)를 확인합니다.
3. 게임 화면에 두 값을 입력합니다. 두 컴퓨터에서 **같은 프로젝트 URL과 같은 공개 키**를 사용합니다.
4. 서비스 계정의 `service_role` 키는 절대 사용하지 않습니다. 공개 키는 클라이언트 앱에 넣는 용도의 키입니다.
5. 별도의 데이터베이스 테이블이나 서버 코드는 만들지 않습니다. Supabase Realtime 연결이 프로젝트에서 사용 가능해야 합니다.

## 방 만들기와 참가

1. 한 명이 **친구와 온라인 플레이 · 방 코드** → Supabase 정보를 입력 → **방 만들기**를 누릅니다.
2. 연결되면 8자리 방 코드가 표시됩니다. 코드를 친구에게 전달합니다.
3. 친구는 같은 Supabase URL·공개 키를 입력하고 **방 코드로 참가**를 누릅니다.
4. 두 플레이어가 연결되면 게임이 시작됩니다. 게임 데이터와 턴은 방을 만든 쪽이 관리하며, 참가자는 자기 차례에 액션을 보냅니다.
5. 브라우저 배포 시 두 사람 모두 itch.io 페이지를 열면 됩니다. IP 주소나 포트 입력은 없습니다.

## Web 빌드와 itch.io

1. Godot에서 **Project → Export… → Add… → Web**으로 Web 프리셋을 추가합니다.
2. Web 내보내기 템플릿이 필요하면 현재 Godot 버전과 같은 템플릿을 설치합니다.
3. 빈 폴더에 `index.html`로 Web 프로젝트를 내보냅니다.
4. 내보낸 파일을 모두 ZIP에 넣습니다. ZIP을 열었을 때 `index.html`이 바로 보여야 합니다.
5. itch.io에서 HTML/브라우저 실행 프로젝트를 만들고 그 ZIP을 업로드합니다.
6. 페이지를 저장하고 브라우저에서 실행을 확인한 뒤 페이지 주소를 친구와 공유합니다.

## 기능별 파일 구성

- `main.gd`: 전체 게임 흐름을 조정하는 컨트롤러
- `holdem_table_ui.gd`: 게임 테이블 표시, 버튼 입력, 시작 핸드 계산기
- `holdem_lobby_ui.gd`: 플레이 방식 선택 및 방 코드 입력 UI
- `game.gd`: 카드 분배, 베팅 규칙, 턴 진행, 승패 및 팟 정산
- `poker.gd`: 카드 표현, 족보 판정, 승률 추정
- `ai_strategy.gd`: AI 성향과 베팅 행동 결정
- `supabase_realtime.gd`: Supabase WebSocket 연결과 메시지 전달
- `stats_tracker.gd`: 오프라인 전적 저장과 통계 창
- `tests.gd`, `ui_test.gd`: 게임 규칙과 UI 흐름 검사

테이블 UI는 행동 요청 신호만 보냅니다. 실제 칩·베팅 변경은 `game.gd`가 검증하며, AI 행동도 `ai_strategy.gd`가 제안하고 게임 규칙이 최종 확인합니다. 네트워크 연결, 로비 UI, 전적 UI도 각각 별도 파일에 있습니다.

**나가기**를 누르면 온라인 연결을 닫고 플레이 방식 선택 화면으로 돌아갑니다. **전적 / 통계**는 시작 메뉴의 플레이 방식 버튼 아래에 배치됩니다.

## 온라인 모드의 한계

- 방 코드는 서버에 등록·예약되지 않습니다. 호스트가 연결된 상태에서만 방이 유지됩니다.
- 누구나 공개 키와 방 코드를 알면 같은 채널에 연결할 수 있습니다. 방 코드는 비밀번호나 강력한 보안 경계가 아닙니다.
- 카드/액션 메시지는 공개 Realtime 채널로 전송됩니다. 클라이언트 화면에서는 상대 카드를 숨기지만, 네트워크를 분석하는 이용자로부터 카드를 안전하게 보호한다고 보장하지 않습니다.
- 호스트가 나가거나 연결이 끊기면 게임을 계속할 수 없습니다. 재접속 후 이어하기는 제공하지 않습니다.
- Supabase 무료 사용량과 현재 정책은 계정·프로젝트의 요금 정책에 따릅니다.

이 소스는 Godot 편집기에서 실행·두 기기 간 통신을 직접 검증하지 않은 상태입니다. Web 내보내기와 실제 연결은 사용자의 Godot/Supabase 설정에서 확인해야 합니다.


모듈 간 호출 순서와 각 파일의 수정 위치는 `ARCHITECTURE.md`에 정리되어 있습니다.
